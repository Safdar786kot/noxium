Specifications

A predictable emission curve

Each block pays slightly less than the one before. Half of all NOX is mined in about 5.5 years. The final atomic unit is mined at block 63,665,387, roughly 242 years after launch. After that, miners are paid only by transaction fees.

Get started

01

Run a node

Download the release, unpack it, and start the daemon. It finds peers and syncs the chain.

./noxiumd --testnet

For a server, use the one-line installer, which sets up systemd and a firewall:

curl -fsSLO https://raw.githubusercontent.com/Safdar786kot/noxium/main/tools/deploy/install-node.sh
sudo bash install-node.sh --network testnet
02

Create a wallet

Write down the 25-word seed. It is the only way to recover your coins.

./noxium-wallet-cli --testnet \
  --generate-new-wallet mywallet

Testnet addresses start with Tx. Mainnet addresses start with Nx.

03

Mine on your CPU

In the running daemon, start mining to your wallet address:

start_mining <your-address> 2

Coins can be spent after 60 blocks. In a brand-new chain, sending also needs about 76 blocks, so there are enough decoys for a ring of 16.

Security first

Before launch, every consensus change was independently reviewed. The full report and the fixes are public.

Read the security review
  • Supply cap proven by test. The cap was simulated to the last block, and the total never exceeds 18,000,000 NOX.
  • Unique network. Noxium has its own network IDs, genesis seed and address prefixes, so it can't be confused with Monero or replay its transactions.
  • No hidden coins. The genesis keys are nothing-up-my-sleeve points with no known private key.
  • Modern rules from block 1. All Monero hard-fork protections are active from the start.
  • Tested. 1,272 unit tests pass, and a multi-node testnet soak plus a reorg test passed with zero mismatches.
  • Private disclosure. Report vulnerabilities through GitHub's private advisory form.

FAQ

How is Noxium different from Monero?

It uses the same privacy technology, but on its own independent network. The difference is supply: Monero has a permanent tail emission, while Noxium stops at exactly 18,000,000 NOX.

What pays miners after emission ends?

Transaction fees. Fees are calculated from a fixed reference reward, so they stay meaningful even after block rewards reach zero.

Was there a premine or ICO?

No. Every NOX is mined in public blocks, starting at launch.

Can I mine with a GPU?

RandomX is designed for ordinary CPUs. GPUs and ASICs have little advantage.

Are testnet coins worth anything?

No. The testnet is for testing only and will be reset as needed. Mainnet starts from a fresh genesis block.
